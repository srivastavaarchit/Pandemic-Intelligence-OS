Quick guide

Four steps to get started

  1. Read the Overview. Check the headline numbers, then switch the wave chart between daily and cumulative, linear and log.
  2. Spin the Map. Drag the globe and select a bubble to see a country’s cases, deaths and fatality rate.
  3. Compare countries. Add a few and see whose curve rose first and flattened fastest.
  4. Try the Simulator. Move the sliders to see how timing and strength of action change the peak.

Good to know

  • Press / from anywhere to jump to a country. Esc closes any panel.
  • Select any country name, row or bubble to open its full history.
  • Figures are reported cases; the dataset runs from January 2020.
